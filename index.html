Sobre mí

Soy Héctor Piquer Belda, de Xàtiva, y estudio 1º de DAM en el IES Simarro. Antes pasé por un Grado Medio de SMR, donde aprendí a montar, mantener y diagnosticar equipos.

Lo del hardware me gustaba, pero lo que de verdad me enganchó fue entender cómo funciona todo por dentro. Por eso di el salto al desarrollo: quería dejar de solo arreglar máquinas y empezar a construir cosas.

No voy de experto, no lo soy. Pero sí soy de los que se queda hasta que lo entiende, ordena el desastre y pregunta cuando hace falta. Prefiero algo sencillo bien hecho que algo prometedor a medias.

Ejercicio de Java (BlueJ)

terminado

Práctica de clase: relleno un array de 100 enteros y calculo su suma y su media con métodos propios. Me sirvió para afianzar arrays, bucles y métodos estáticos.

  • Java
  • BlueJ
  • arrays
ver código 
public class Exer10 {
  public static void main(String[] args) {
    int[] valores = new int[100];
    for (int i = 0; i < 100; i++) valores[i] = i + 1;

    System.out.println("Suma: " + suma(valores));
    System.out.println("Media: " + media(valores));
  }
  public static int suma(int[] v) {
    int s = 0;
    for (int i = 0; i < 100; i++) s += v[i];
    return s;
  }
  public static int media(int[] v) {
    int s = 0;
    for (int i = 0; i < 100; i++) s += v[i];
    return s / 100;
  }
}
