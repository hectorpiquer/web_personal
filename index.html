Ejercicio de Java (BlueJ)

terminado

Práctica de clase: relleno un array de 100 enteros y calculo suma y media con métodos propios. Me sirvió para afianzar arrays, bucles y métodos estáticos.

  • Java
  • BlueJ
  • arrays
ver código 
public class Exer10 {
  public static void main(String[] args) {
    int[] valores = new int[100];
    for (int i = 0; i < 100; i++) valores[i] = i + 1;

    System.out.println("Suma: " + suma(valores));
    System.out.println("Media: " + media(valores));
  }
  public static int suma(int[] v) {
    int s = 0;
    for (int i = 0; i < 100; i++) s += v[i];
    return s;
  }
  public static int media(int[] v) {
    int s = 0;
    for (int i = 0; i < 100; i++) s += v[i];
    return s / 100;
  }
}

Caso estrella: esta web como proyecto

Problema

Quería mostrar un perfil técnico —base SMR, DAM en curso— sin parecer plantilla vacía ni cajón de cosas sin hilo. Hacía falta una sola voz, y la mía venía de sistemas.

Solución

Mono-página con secciones por hash, fondo de nodos en canvas que habla de redes sin ser decorativo, intro de terminal que explica quién soy en dos segundos, cuatro APIs públicas sin clave (Hacker News, Open-Meteo, GitHub, iTunes), test de orientación con radar, arcade propio y formulario real. Todo con prefers-reduced-motion, foco atrapado en diálogos y semántica accesible.
